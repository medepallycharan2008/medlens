# Automated Testing Documentation - MedLens

MedLens uses a modern, deterministic, headless testing architecture powered by **Vitest 5**, **React Testing Library**, **@testing-library/jest-dom**, and **jsdom**. All tests run completely offline without relying on real external APIs or network downloads.

---

## 1. Test Architecture & Stack

- **Test Runner & Assertion Engine**: [Vitest 5](https://vitest.dev/)
- **DOM & Component Testing**: [React Testing Library](https://testing-library.com/) + `@testing-library/jest-dom`
- **Environment**: `jsdom` (in-memory DOM simulation)
- **Coverage Provider**: `@vitest/coverage-v8`
- **Mocks & Isolation**:
  - Deterministic in-memory `LocalStorage` mock configured in `src/test/setup.ts`.
  - Mocked `tesseract.js` worker preventing remote traineddata network requests during test runs.
  - Automatic test isolation and DOM cleanup after every test execution.

## 4. Key Healthcare Logic Assertions

1. **Strict Reference Range Non-Inference Rule**:
   - If a clinical document does not explicitly state a reference range, MedLens **never** invents or assumes a standard range.
   - Status evaluates strictly to `NOT_DETERMINABLE`.
   - The user is shown clear explanatory guidance (`"No reference range stated on document"`).
2. **Audit Preservation on Manual Edit**:
   - When medical staff or doctors edit an OCR extraction, the original OCR values are immutably archived under `originalExtraction`.
   - Status changes to `EDITED` and an audit entry is logged to the timeline.
3. **Dual Verification Pipeline**:
   - Documents progress through explicit stages:
     - `PENDING_VERIFICATION` &rarr; Patient reviews and confirms identity (`PATIENT_CONFIRMED`).
     - Doctor conducts clinical review and signs off (`DOCTOR_VERIFIED`).
   - If rejected, a mandatory clinical note is recorded (`REJECTED`).

## 5. Limitations & Regulatory Disclaimer

- **Prototype Nature**: MedLens is designed as an educational prototype and clinical assistive tool.
- **Non-Diagnostic**: Summaries generated by MedLens are strictly non-diagnostic and designed for assistive organization.
- **OCR Constraints**: Tesseract.js client-side OCR performance depends on document scan resolution, lighting, and layout cleanliness.
